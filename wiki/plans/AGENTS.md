# Temporary Plan Guide

This directory contains plans for active implementation work, not historical records.

- Save an agreed, decision-complete plan as `wiki/plans/<task>.md` before implementation.
- Link the authoritative `wiki/docs/` sources and existing component notes that govern it.
- State verification and documentation-reconciliation requirements.
- Update the plan while the task is active when the agreed implementation changes.
- After implementation and verification, reconcile durable facts into the source documents
  and component notes, then delete the completed plan.
- Do not archive completed plans or treat a plan as authority over `wiki/docs/`.

`index.md` lists active plans only.
