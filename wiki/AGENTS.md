# Legacy Wiki Archive Guide

`wiki/` is an archived Obsidian vault and is not a source of truth. Maintained game designs,
technical contracts, roadmap state, and completion tracking live in `docs/`.

Do not read, reconcile, validate, or update this archive during normal development. Only
modify it when the user explicitly requests archive work. Never change `.obsidian/` reader,
workspace, application, or theme state.

When archive work is requested, preserve historical meaning and use relative Markdown links
for references to maintained documents under `../docs/`.
