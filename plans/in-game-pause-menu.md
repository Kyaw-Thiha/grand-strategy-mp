# In-Game Pause Menu Plan

## Goal

Add a visual-only in-game pause menu to the current game scene.

## Phases

1. Create a pause menu scene and script with Continue, Settings, How to Play, and Quit buttons.
2. Instance the pause menu in the current game scene.
3. Route Escape and menu-visible input through the pause menu before map/military input.
4. Validate the pause menu scene and current game scene with Godot headless loads.
